# 商业模式与合规红线（正式版 v2.0）

> 生效日期：2026-11-09。相关配置：`config/brand.yaml` 的 `business` 段、
> `config/content_rules.yaml` 的 `compliance` 与 `collaboration` 段。
> 本文件只定义**商业模式与边界**，不承诺任何收入数字。

## 1. 收入结构（四条线）

| # | 收入线 | 形态 | 状态 |
| --- | --- | --- | --- |
| 1 | 免费公开内容 | 抖音/小红书/bilibili/公众号内容 → 获客与信任积累 | 建设中（内容生产链路未接通） |
| 2 | 会员服务 | 深度报告、专题研究、知识库、交流服务 | 未开始（需先有稳定内容产能） |
| 3 | 系统课程 | 金融基础、金融市场、产业链研究、企业商业模式分析 | 未开始 |
| 4 | 商业合作 | 品牌合作、内容制作、研究合作 | 未开始（须先建立披露机制） |

四条线的顺序不能倒：**先免费内容建立专业信任，再谈付费**。
在没有稳定内容产出前，不启动会员与课程预售。

## 2. 免费内容：获客与信任

- 目标不是流量最大化，而是"被正确的人记住"。
- 六大合集轮转，避免单一人群过窄；但每期选题必须独立成立。
- 免费内容的深度决定付费产品的说服力：**免费内容不许做成"付费内容的删减版"**，
  免费讲清机制，付费提供数据、模型与可复用的研究框架。

## 3. 会员服务

**可以包含**

- 深度研究报告（含数据表、模型假设、局限性）
- 专题系列（一个产业链/一家公司/一个事件的完整拆解）
- 知识库检索与更新（`knowledge_items` 的整理成果）
- 交流与答疑（讨论机制、方法与资料，**不讨论具体买卖**）

**不可以包含**

- "会员专享标的池""内部消息""建仓时机"
- 针对个人资金情况给出配置比例、买卖点
- 代客理财、代客下单、代管账户

## 4. 系统课程

- 结构：金融基础 → 金融市场 → 产业链研究 → 企业商业模式分析。
- 每门课必须有明确学习路径、练习与可核对的答案标准。
- 课程内容以"方法"为核心交付物：如何查一手资料、如何读财报、如何拆产业链，
  而不是"背结论"。
- 涉及具体公司时，只能作为**案例分析**，且必须注明数据时点与来源。

## 5. 商业合作与利益披露

规则（已在 `config/content_rules.yaml#collaboration` 落地）：

1. 合作必须显著披露：片头或口播明确说明，"本期内容包含与 X 的商业合作"。
2. 品牌方不得参与研究结论与脚本定稿。
3. 出现"删改不利结论"要求时，**必须终止合作**并在内容中说明原因。
4. 广告不得伪装成知识科普或案例研究。
5. 不接受以"推荐买入某标的"为交付物的合作。

披露模板见 `config/content_rules.yaml` 的 `collaboration.disclosure_text_template`。

## 6. 合规红线（最高优先级）

本项目做**金融教育 + 公开资料研究 + 商业分析**，不做证券投资咨询。
一句话概括红线：**付费可以买方法、数据与研究，不能买"该买什么"**——
收费荐股、收荐股费、代客理财都在永久禁止之列。

| 允许 | 禁止 |
| --- | --- |
| 讲金融产品机制、定价逻辑、风险结构 | 推荐买/卖某只股票、基金、债券 |
| 分析公开财报、监管文件、行业数据 | 给出目标价、点位、仓位、止盈止损 |
| 复盘历史事件与商业案例 | 提供"内幕消息"、暗示确定性收益 |
| 讲方法论：怎么查、怎么算、怎么验证 | 针对具体个人给出个性化投资建议 |
| 收会员费/课程费（卖方法、卖研究） | 收荐股费、代客理财、代管账户 |

**判定口径**：一句话若在"换到任意一个读者身上都还成立"，属于教育；
若它依赖"你是谁、你有多少钱、你的风险偏好"，就是个性化咨询 —— 本项目不产出后者。

其他硬约束：

- 所有内容带免责声明（成片片尾 ≥5 秒、图文首屏或文末、会员报告封面页）。
- 出现 `human_review_triggers` 关键词（推荐买入/稳赚/抄底/满仓/目标价…）即强制人工复核。
- 数据必须带币种、单位、时点、辖区；跨境案例须写明适用司法辖区。

## 7. 成本与基础设施原则

- 初期预算优先：不买云服务器、不配付费 API、不用 K8s/微服务/独立向量库。
- 现有技术栈（本地 FastAPI + SQLite + 本地文件 + 未来 FFmpeg/Matplotlib）足以支撑到
  "稳定周更 + 会员起步"阶段。
- 付费投入的顺序：**先买数据/资料（研究质量）→ 再买算力（生产效率）→ 最后才是分发**。

## 8. 风险清单

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 内容滑向"荐股" | 合规风险，平台处罚 | 关键词闸门 + 人工终审 + 免责声明 |
| 商业合作影响结论 | 可信度崩塌 | 强制披露 + 终止合作条款 |
| 产能不足导致断更 | 增长停滞 | 研究报告复用（一报告多产品）+ 模板化生产 |
| 付费产品质量与免费内容同质 | 会员流失 | 付费必须提供数据、模型、可复用框架 |
| 单点依赖个人 | 生病/忙碌即停更 | 知识资产沉淀 + AI 研究流水线 |
| 版权与引用风险 | 法律纠纷 | 一手来源优先 + 引用规范 + 不使用未授权素材 |

## 9. 待你决定的事项

1. 会员形态：纯研究报告订阅，还是报告 + 社群？两者成本差异大。
2. 课程上线顺序：先"金融基础"还是先"产业链/公司分析"（后者更贴合当前内容优势）。
3. 商业合作的接单红线：哪些行业直接不接（如荐股类、代币类、高杠杆产品）？
4. 定价策略：定价必须等免费内容稳定产出后再定，避免过早锁死定位。
