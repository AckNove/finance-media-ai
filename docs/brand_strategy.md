# 品牌战略（正式版 v2.0）

> 生效日期：2026-11-09。本文件是品牌层面的**唯一真相**，机器可读配置在
> `config/brand.yaml`；内容分类在 `config/content_taxonomy.yaml`。
> 与旧版本的差异见第 8 节。

## 1. 品牌架构：两层，不要混用

| 层级 | 名称 | 出现位置 | 说明 |
| --- | --- | --- | --- |
| 个人 IP | **电力之王AK** | 账号主页、头像、口播自称、评论区署名 | 对外唯一账号名。主页**只显示这个**，不额外挂正式品牌名 |
| 内容品牌 | **AK带你拆解世界** | 内容片头/片尾、栏目名、报告封面、课程名称 | 内容产品的署名与栏目归属 |

**关于"电力之王AK"**：名称中的"电力"是创作者的昵称与品牌记忆点，
**不代表账号专门研究电力行业**。账号内容按六大合集组织（见 `docs/content_strategy.md`），
任何把本账号理解为"电力行业号"的定位都是错的。

## 2. 品牌核心

**主张（一句话）**

> 用金融与商业视角，拆解世界运行的逻辑。

**定位**

> 一个以金融与商业研究为核心，通过金融知识、财经时事、产业链、公司和商业案例，
> 帮助大众理解世界运行逻辑的个人知识品牌。

**使命**

> 把复杂的金融和商业问题讲清楚，让更多人看懂新闻背后的逻辑、行业背后的利益关系，
> 以及企业背后的经营规律。

**品牌个性（五条，落地时按此自检）**

| 个性 | 含义 | 反面（禁止） |
| --- | --- | --- |
| 专业 | 先讲清机制，再谈观点 | 术语堆砌、概念含糊 |
| 犀利 | 敢下判断，但判断必须有证据 | 阴阳怪气、人身攻击 |
| 独立 | 不为流量与商业合作改变结论 | 看风向改口、为甲方站台 |
| 有趣 | 可以幽默，但不低俗、不油腻 | 段子化、擦边 |
| 求真 | 宁可说"不知道"，也不编造 | 编数据、假引用、猜来源 |

## 3. 受众

覆盖六类人群（普通大众、财经热点关注者、金融学习者、产业链与公司研究爱好者、
创业者与企业经营者、商业研究爱好者），分三个认知层次：

| 层次 | DB 取值 | 内容特征 |
| --- | --- | --- |
| 大众认知 | `beginner` | 零术语门槛，用生活场景切入 |
| 进阶学习 | `intermediate` | 讲机制、算例与对比 |
| 深度研究 | `advanced` | 讲口径、数据、模型与争议 |

**原则**：覆盖面靠"同一选题的多版本"，不靠稀释专业度。
不能为了覆盖全部人群而降低专业质量——这条优先级高于流量。

## 4. 表达风格（可执行标准）

**核心要求**：观点鲜明、犀利、有趣。

必须做到：

1. 专业但不卖弄术语——术语首次出现给英文原文 + 一句话解释。
2. 有观点但不脱离证据——每个判断都能指回 `evidence`。
3. 可以幽默、调侃，但不低俗、不嘲讽具体的普通人。
4. 不做简单新闻搬运——热点必须给出增量分析。
5. 善于从热点中提出值得思考的问题——开头 8 秒是"问题"，不是"标题复读"。
6. 以真实案例和数据解释金融与商业逻辑。
7. 研究结论必须可追溯到可靠来源。

明确禁止：

- 为趣味性扭曲真实金融机制
- 用足球类比替代真实定义与公式
- 承诺收益、暗示稳赚、暗示内幕
- 面向个人的具体买卖建议（标的/点位/仓位/时点）
- 用情绪替代证据（"震惊""崩了""全都完了"式表述）

完整规则见 `config/content_rules.yaml` 的 `style` 与 `compliance`。

## 5. 视觉与出镜

**整体视觉风格**：专业研究 + 纪录片叙事 + 适当幽默。

- 默认画布 1080×1920 / 30fps / 竖屏，适配抖音与小红书；
  深度纪录片可出 16:9 版本供 bilibili。
- 深色底 + 高对比数据色，图表优先于装饰；不使用土味特效与廉价花字。
- 字幕与字号规范见 `video_engine/subtitles/README.md`。

**出镜策略：选择性真人出镜。**

| 内容类型 | 出镜方式 |
| --- | --- |
| 重要专题 / 品牌代表作 | 真人出镜 |
| 常规知识科普 | AI 图解 + 授权 AI 声音（无人出镜） |
| 数据密集型研究 | 纯图解 + 配音 |

声音来源允许：本人录音、明确授权的 AI 声音、无配音的图解动画。
禁止模仿未授权的第三方声音。

## 6. 品牌与内容的关系

- 品牌主张决定"为什么做"，六大合集决定"做什么"，Agent 团队决定"怎么做"。
- 合集不是账号：一个账号、一个 IP、六类内容；未来允许新增合集，不设上限。
- 足球是六大合集之一（`football_finance`），也是讲机制时的高关注度类比场景；
  **它不是账号的内容边界**。

## 7. 一致性自检清单（每次发布前）

1. 开头是否提出了一个值得思考的问题（而不是复述新闻）？
2. 是否有明确判断？判断是否都能指回证据？
3. 事实 / 推断 / 观点是否分开说？
4. 重要数字是否带币种、单位、时点、辖区？
5. 用了足球类比？是否说了"哪里成立、哪里不成立"？
6. 有没有滑向买卖建议、收益承诺、"内幕"？
7. 有商业合作？是否在显著位置披露？
8. 主页/片头署名是否用了正确的层级（IP 名 vs 内容品牌名）？

## 8. 与旧策略的差异

| 项目 | 旧版本（第一阶段初稿） | 正式版本（v2.0） | 变更理由 |
| --- | --- | --- | --- |
| 账号名 | 未定义（只有项目代号 `finance-media-ai`） | 个人 IP：**电力之王AK** | 需要对外账号身份与记忆点 |
| 内容品牌 | `display_name: 金融知识研究台`（占位） | **AK带你拆解世界** | 正式品牌名确定 |
| 品牌主张 | `用足球讲金融，用金融看世界` | **用金融与商业视角，拆解世界运行的逻辑** | 原主张把足球放在中心，与"金融+商业双主线、足球仅一个合集"的定位冲突 |
| 内容主线 | 金融知识为主，足球作教学隐喻 | 金融与商业**并重**，六大合集 | 商业研究（产业链、公司解剖）升级为一等公民 |
| 足球定位 | 教学隐喻，"不是内容边界" | 既是教学场景，也是独立商业研究领域（六大合集之一） | 提高足球内容的独立价值，同时明确不设边界 |
| 表达风格 | 专业金融讲解 + 适度幽默 | 观点鲜明、犀利、有趣（含禁用清单） | 旧表述过于保守，缺少"敢下判断"的要求 |
| 受众 | 有一定学习能力的成年人 | 六类人群 × 三层次，明确"不为覆盖降质量" | 目标受众正式扩大并结构化 |
| 商业模式 | 未定义 | 免费获客 / 会员 / 课程 / 商业合作四线 + 披露规则 | 补上变现与合规边界 |
| 内容形式 | 只有四类视频模板 | 8 种形式（60–120s / 2–5min / 5–15min / 图文 / 报告 / 系列 / 会员 / 课程） | 形式与产品形态解耦，按选题价值选择 |
