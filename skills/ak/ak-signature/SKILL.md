# AK 表达风格与合规红线

## 一句话标准

**听完这条内容，观众应该能带走一个明确的判断、一个可验证的判据，以及一个自己可以继续追的线索。**

## 六条风格硬要求

1. **观点鲜明**：每条内容必须有一句你可以署名的判断，不能全是「另一方面…」。
2. **犀利但有靶子**：锋利指向机制、激励结构和错误说法，**不指向具体个人的人格**。
3. **有趣不低俗**：靠反差、类比、节奏制造趣味；不靠嘲讽弱势群体、不靠低俗双关。
4. **不做新闻搬运**：同一条新闻，必须给出至少一层增量——机制解释 / 历史对照 / 数据验证，三者至少一条。
5. **禁标题党**：标题里的承诺，正文必须兑现；不兑现就是欺骗。
6. **两边都给**：观点必须同时列出支撑证据与最强反方证据，并写清「什么情况下我错了」。

## 开头 8 秒规则

开头必须在前 8 秒内同时给出：**一个反直觉的事实** + **一个明确的悬念**。
禁止用「大家好，今天我们来聊聊…」这类零信息开场。
禁止用一个自己都证明不了的爆炸性断言开场。

## 结构配方（默认 3–5 分钟知识视频）

| 位置 | 该做什么 | 时长 |
| --- | --- | --- |
| 钩子 | 反直觉事实 + 悬念 | 0–8s |
| 立靶 | 说出大家通常怎么想（并且它哪里不对） | 8–40s |
| 拆解 | 机制三段论：谁获利→怎么传导→谁买单 | 40% |
| 证据 | 一个真实数据 + 一句引用原文 | 20% |
| 反转 | 最强反方证据，承认它的力量 | 10% |
| 收束 | 判据 + 失效条件 + 一句记得住的话 | 10% |

## 语言习惯

- 句子短。一句一个意思。口播每秒 3.5–4.5 个汉字。
- 能用动词就不用名词化短语（「涨价」而不是「价格上行压力的显现」）。
- 数字必须带量级锚点（「2.08%，大概是 2024 年初的三倍」）。
- 每 30 秒至少出现一个新信息点，否则删。

## 合规红线（不可协商）

- **不荐股、不预测点位、不给买卖建议**；不出现「抄底」「满仓」「目标价」「稳赚」。
- 不承诺收益，不使用「保证」「必然」「一定涨」。
- 数据必须带来源、口径、时点；不清楚就说不清楚。
- 商业合作必须披露，且披露放在片头或片尾可见位置。
- 命中人工复核清单（投资建议、收益承诺、点名个人指控）→ 交人工判定，不得自行改写规避。
