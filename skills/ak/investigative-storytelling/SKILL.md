# 深度研究与故事结构

## 何时使用

- 手上有一批资料（财报、新闻、数据表、访谈），但不知道从哪讲起。
- 写出来的东西像资料汇编，没有冲突、没有人物、没有「所以呢」。
- 要给一个结论，但担心站不住。

## 研究四件套（缺一件就不是调查）

| 件 | 内容 | 落盘位置 |
| --- | --- | --- |
| 1 时间线 | 什么时候发生了什么，谁先动的手 | `research_notes.md` 的「时间线」节 |
| 2 关键人物/机构 | 谁受益、谁受损、谁有决定权 | `research_notes.md` 的「角色」节 |
| 3 利益结构 | 钱从谁流向谁，风险最后落在谁头上 | `research_notes.md` 的「资金与风险」节 |
| 4 反方证据 | 最能推翻我结论的那条证据 | `fact_check.md` 的「反方证据」节 |

**没有第 4 件，结论只能写成「推测」，不能写成「事实」。**

## 证据分级（写作时必须标注）

| 级别 | 含义 | 允许怎么写 |
| --- | --- | --- |
| E1 原始数据 | 一手数据文件、原始报表、监管披露 | 可直接作为事实陈述，须注明文件与字段 |
| E2 权威转述 | 官方机构、交易所、统计局的公开表述 | 可作事实，须注明机构与日期 |
| E3 媒体报道 | 通讯社、专业媒体 | 「据 X 报道」+ 链接，不得当作已核实事实 |
| E4 观点推测 | 任何人的判断，包括你的 | 必须写「我的判断是」并给失效条件 |

跨级使用是硬错误：**E3 不能当 E1 用，E4 不能当 E2 用。**

## 故事结构（五幕，不是论文结构）

1. **异常**：一个说不通的现象或一个反常的数字。
2. **常规解释**：大家通常怎么解释它（并且它哪里不够用）。
3. **追下去**：翻资料，发现另有一条线（人物/资金/制度）。
4. **机制**：把这条线拼成因果链，指出关键节点。
5. **代价与判据**：谁付账；以及**未来看到什么就说明我错了**。

第 5 幕的「失效条件」是硬要求：没有失效条件的结论不许发布。

## 引用与可核查

- 每个事实句后面挂 `[S编号]`，S 编号对应 `source_register.csv` 的行。
- 数据必须带：口径、单位、时点、来源文件。
- 引用原文必须能回到 `source_text/` 里的具体文件与位置；不能回指的引文视为未核实。

## 禁止事项

- 阴谋论式断言（「他们故意……」，除非有直接证据）。
- 把相关性写成因果（「A 涨之后 B 涨，所以 A 导致 B」）。
- 用「业内人士称」掩盖没有来源。
- 为了故事张力调整数字顺序或省略不利数据。

## 自检清单

- [ ] 时间线是否有明确起止日期
- [ ] 是否至少有一个具体角色（不是「市场」这种抽象主体）
- [ ] 资金流向能否用一句话说清
- [ ] 反方证据是否被认真对待过（不是稻草人）
- [ ] 结论是否带失效条件
- [ ] 每个数字是否可回溯到 `source_register.csv` 的一行
