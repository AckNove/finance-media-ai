# 视觉导演：这五幕怎么拍

> 视觉导演的工作不是写一句「请做得有电影感」，而是给出**可以被程序执行的镜头设计**：
> 每个镜头的主体、层次、摄影机、动画事件、出现顺序、时长、转场、资产、音频、证据。
> 落地形式是 `remaster_v1/blueprint/scenes/s*.json`（由 `backend/app/video/cinema/blueprint.py` 校验，未知字段一律拒绝）。

## 0. 总体视觉语言（五镜共用，不许各自为政）

| 维度 | 规则 |
|---|---|
| 画幅 | 1080×1920 竖屏，30fps，安全区左右各留 6% |
| 色彩 | 深海军蓝底（`#04060b`→`#1f3b5c` 径向）、信息色只用三种：青 `#35e0ff`（容量/新逻辑）、黄绿 `#b6ff1f`（强调/结论）、琥珀 `#ffb020`（旧逻辑） |
| 字体 | Noto Sans SC（OFL-1.1），一个字重，**不描边不阴影**，靠压暗层拉开对比 |
| 材质 | 三维只有两种材质：深色金属杆件（塔）+ 自发光小体（电流、锚）；二维只有色块、细线、大字 |
| 光影 | 无主光打脸，只有天光 + 低位点光；画面靠**压暗层（scrim）+ 暗角**收边 |
| 运动 | 三维：摄影机推近/横移；二维：柱子长高、芯片位移、数字滚动。**任何一个运动都必须对应一个信息变化** |
| 转场 | 不叠化到底：靠摄影机连续运动 + 信息层换场；镜头之间允许 0.3–0.5s 的黑场呼吸 |
| 文字 | 每屏最多三级：kicker（6–9 字）→ 标题（≤3 行）→ 说明（≤2 行）；来源行常驻底部 |
| 数据 | **只画确认过的数字**；柱高比只表达"升/降"方向，不假装是精确比例 |

## 1. 镜头设计（逐镜）

### S1 悬念 · 5.68s

- **叙事任务**：让观众先站在夜里运行的电网前面，再被一句反直觉的话顶住。
- **构图**：三层纵深——近景一根塔（右下出画）、中景三根塔排成斜线、远景地平线与网格。文字压在下 1/3。
- **摄影机**：`[0,2.6,13]` → `[1.2,2.2,9.4]`，fov 38→34，缓慢推近并把视线压低到地平线上方。
- **动画事件**：塔逐根 `enter`（0.1s 起错峰）；两条电流沿导线从近端流向远端；文字 1.4s 拉起。
- **声音**：低频环境垫 + 一次 `whoosh` 承接文字出现。
- **证据**：S01+S02（"两张账单"这句话的出处）。

### S2 机制 · 10.31s —— 本片信息密度最高的一幕

- **叙事任务**：让观众**看见两根柱子朝相反方向走**。
- **构图**：上 1/4 标题；中部两组柱列（左冷色三根、右黄绿三根），中间留空当"断开"；中下一条基线；底部说明与来源。
- **摄影机**：几乎不动（`[0,1.5,13]`→`[0.4,1.5,12]`），把稳定性让给柱子。
- **动画事件**：①左柱 `keyframes` 逐步变矮（电量在掉）②右柱逐步长高（待命也能收）③基线保持水平不动（强调"同一把尺子"）④说明句 6.0s 出现。
- **声音**：柱子每变一次高度配一次 `tick`；结尾 `impact`（一句"两根柱子，各算各的账"）。
- **证据**：S02（容量电价机制）+ S01。
- **为什么不是一张图**：静态对比图只能给结论，逐帧此消彼长才让观众自己发现"两条曲线在分叉"。

### S3 转折 · 6.16s

- **叙事任务**：让观众**看见一个锚从旧资产移到新资产**。
- **构图**：左右两张资产卡（金=红利资产、青=AI 的能源底座），卡内各一个大字（息 / 算），中间一条水平轨道；下方是结论标题。
- **摄影机**：横移跟随锚（`x −0.4 → 0.4`），让"移动"有方向感。
- **动画事件**：①左卡 0.2s 出现 ②锚芯片 1.5s 亮起 ③2.6s 起锚沿轨道右移 ④4.4s 抵达右卡、左卡压暗 ⑤标题 0.8s、结论句 4.6s。
- **声音**：锚移动配 `riser`（情绪抬升），抵达配 `impact`。
- **证据**：S01（算电协同 → 估值锚迁移）。
- **诚实边界**：锚的移动是**比喻**，不是数据；因此画面里不出现任何百分比，避免观众误读成"迁移了 62%"。

### S4 反证 · 12.10s

- **叙事任务**：让观众**看见总量线不动、份额在变**，理解"再分配"。
- **构图**：顶部 6.2% 数字（滚动）+ 一行说明；中部一条水平总量线（不动）+ 四根份额柱（此消彼长）；底部结论"总量没变，变的只是分法"。
- **摄影机**：轻微横移，制造纵深，不干扰读数字。
- **动画事件**：①6.2% 从 0 滚到 6.2（1.2s）②四根柱 `keyframes` 交叉变化 ③总量线全程不动 ④结论 7.5s。
- **声音**：数字滚动配 `tick` 阶梯；柱交叉时一次 `whoosh`。
- **证据**：S11（2026H1 利润同比 −6.2%）、S12。
- **诚实边界**：四根柱代表"份额在变"的结构示意，**不是四家公司真实份额**，因此柱上没有百分比标签；画面只允许出现 S11 的 −6.2% 这一个真实数字。

### S5 结论 · 13.47s

- **叙事任务**：把镜头拉远、把话收成一句。
- **构图**：塔群重新回到画面（比 S1 更远），文字占下 1/2，最后 3 秒出现来源与免责。
- **摄影机**：反向拉远 `[0.6,2.2,8]` → `[0,2.8,16]`，让空间说"收尾"。
- **动画事件**：①文字逐行出现 ②两条电流并成一条（呼应"分法变了"）③免责与来源 9.5s 起。
- **声音**：音乐降到只剩低频；结尾一次 `impact` 收。
- **证据**：S01+S02+S11 综合。

## 2. 三种视觉能力怎么分工

| 能力 | 用在哪 | 为什么 |
|---|---|---|
| 三维场景（three.js） | S1、S5 的电网空间；S2/S3/S4 的网格地面 | 提供**空间与气氛**，让画面不像 PPT；不承担数据 |
| 二维动态图形（DOM 面板） | S2/S4 的柱列与总量线、S3 的资产卡与锚 | 数据必须读得准：色块、边界、高度都是可控像素 |
| 融合表达 | 三维地面上叠二维柱列（S2/S4），锚在二维卡之间移动（S3） | 空间给"这里有一张网"，二维层给"钱怎么走" |

**这一条是本次最重要的技术决策**：三维里被点光照着的柱子，颜色随角度变化，观众没法把它当"读数"；所以**数据一律走二维层，三维只做场景**。

## 3. 每个镜头必须过的检查

1. 有没有一条**只有画面才能表达**的信息？（否则就是朗读）
2. 运动是否对应信息变化？（无意义的缩放一律删）
3. 文字是否只在解释画面，而不是替代画面？
4. 关键数字是否有来源行？
5. 与上一镜的风格是否同一套色/字/材质？

## 4. 已知取舍与未做到的部分

- 没有真实影像素材（版权与授权未批）：**全片为程序生成的图形与三维几何**，不是实拍，也不冒充实拍；画面左下/底部均标注来源与"资料整理"。
- 三维塔是几何拼出来的示意塔（杆件 + 横担），不是真实塔型建模；远景有雾，近景没有做贴图材质。
- 没有人物、没有实景、没有无人机镜头——这些需要真实素材授权后才能做，本轮不做假。
- 音效是**程序合成的**（`backend/app/video/cinema/audio.py`），不是采样库素材；许可与来源就是本仓库代码。
