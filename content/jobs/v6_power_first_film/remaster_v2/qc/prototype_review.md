# V2 15–20 秒验证片段：镜头级质量评审（第二版）

评审对象：`content/jobs/v6_power_first_film/remaster_v2/output/prototype_15_20s.mp4`
（18.000 秒 / 1080×1920 / 30fps / H.264 + AAC 48kHz 立体声 / 9,464,749 B / −15.9 LUFS）

用户对第一版的反馈原话：「整体还不错，但是还是没有做到『巫师财经』那种质感」。
这一版就是针对这句话改的，改动集中在**节奏、数据层、质感**三件事上。

**结论：技术 QC 8/8 全过，作品评分 81.1（第一版 78.2），仍未过 85 关口。**

## 1. 相比第一版改了什么

| 项 | 第一版 | 这一版 |
| --- | --- | --- |
| 画面数量 | 3 个（平均 6 秒一镜） | **6 个（平均 3 秒一镜）**，旁白仍连续不打断 |
| 素材裁切 | 一镜一景别 | 同一张实拍拆成远景／特写两镜，靠运镜与裁切做出切点 |
| 数据层 | 两根粗柱子浮在画面上 | **暗衬底 + 基线 + 刻度 + 柱子 + 带底衬标签 + 结算口径说明**，颜色分冷暖 |
| 标注 | 无 | 设备特写镜加**引线标注**（变压器 / 母线各指一次） |
| 质感 | 无颗粒 | 末端加 **暗角（vignette）+ 极细颗粒（noise）**，压掉"数码平"的感觉 |
| 三维 | 灯杆挡住画面、材质发白 | 灯杆移出路径、重排相机、材质压深、地面贴图加强 |
| 音效 | 3 种（whoosh/tick/impact） | 4 种（新增 **spark**，点数据冒出来那一下） |

## 4. 「巫师财经那种质感」到底差在哪（逐条对照）

| 他的特征 | 我们现在 | 差距性质 |
| --- | --- | --- |
| 大量**动态**实拍素材（新闻片、纪录片、企业宣传片、影视片段）混剪 | 只有**静照**，靠摄影机推拉制造运动 | **素材类型差距**，不是技术差距。静照再怎么推也推不出"现场在发生什么" |
| 每 2–4 秒一个镜头，画面永远在动 | 3 秒一切，已接近 | 基本追平 |
| 数据层极克制：细线、刻度、标注、追踪线 | 已做到暗衬 + 基线 + 刻度 + 标签 | 接近，但缺"追踪线/高亮区域/数字跳动" |
| 低饱和青蓝 + 琥珀高光，重颗粒 | 已加青蓝调色 + 颗粒 + 暗角 | 接近 |
| 声音：低频 pad + 转场 whoosh + 重点 impact，层次分明 | 程序化合成 4 种音效，音乐是单层 pad | **差距明显**，配乐需要真正编曲 |
| 图文排版像报告：地图、时间轴、编号、引文条 | 只有标题 + 数据层 | **差距明显**，缺"信息层"（地图/时间轴/编号/引文） |
| 三维很少用，用也只做"示意图" | 我们用了 3.2 秒 | 方向相反：他的真实感来自实拍，不来自三维 |

**一句话结论**：技术链路已经够用，剩下的差距**主要是素材类型（静照 vs 动态影像）和声音设计（合成 pad vs 编曲配乐）**，
这两件都不是"再调参数"能补的。

## 5. 要继续往上走，只有三条路

1. **拿到动态素材**（效果最大）：用户提供，或授权可商用的电力行业视频（新闻/企业宣传片/纪录片片段）。
   哪怕只有 3–5 段 5 秒的镜头，真实感会有质的变化。
2. **声音设计升级**：把程序化合成的单层 pad 换成"低频脉冲 + 和声垫 + 高频空气感"三层，配乐按段落情绪变化。
3. **信息层加厚**：加地图（电厂/变电站/用户的空间关系）、时间轴（2020 政策 → 2024 煤电容量电价 → 2026 利润变化）、
   编号标签（第一张收入表 / 第二张收入表），这是他那种"信息密度感"的真正来源。

技术侧还能做但不解决根本问题的：三维材质贴图、追踪线动画、数字跳动。
