# 制作与质检模板（production）

## 输入

- 脚本：`script_id={{script_id}}`（状态必须为 approved）
- 分镜：`{{storyboard}}`
- 画布：1080×1920 / 30fps / 9:16
- 平台：{{platforms}}

## 你要产出两样东西

### 1. render spec

按 `agents/video_producer/PROMPT.md` 第 4 节结构输出，字段必须完整：

- `canvas`、`timeline[]`（含 `layers[]`）、`subtitles`、`audio`、`output`
- 所有引用的素材必须同时列进 `assets_required`

### 2. QC 结果

按 `video_engine/quality_control/qc_checks.yaml` 的检查项逐条判定，
`status` 只能取 `pass` / `fail` / `not_applicable`（`not_applicable` 需写明原因）。

## QC 判定纪律

- 任何 `blocker` 级 fail → 整体 `passed=false`，不得进入人工终审。
- 每项 fail 必须给 `required_fix`，且修改后可立即重跑。
- 不能因为"看起来问题不大"就把 fail 记成 pass。

## 输出

```json
{
  "summary": "...",
  "render_spec": {...},
  "qc": {"passed": false, "checks": [{"item": "canvas", "status": "pass", "detail": "1080x1920@30fps"}]},
  "assets_required": [{"type": "voiceover", "file": "vo_001.wav", "text": "...", "duration_seconds": 10}],
  "limitations": "本阶段未接入渲染引擎与 TTS，以上为规格与质检结论，未产出成片",
  "handoff": {"next_agent": null, "reason": "需人工终审后再发布"}
}
```

## 禁止

- 声称已渲染出视频（没有渲染就是没有）。
- 跳过质检项。
- 自动发布到任何平台。
- 使用未授权音乐素材（`bgm` 保持 `null`）。
